### Fase 5 — Estabilidade, bugs críticos e UX admin (14/11/2026)

**v47 — Imagem decorativa no card Atendimento (index.html)**

- Asset já existia em `/assets/` e no STATIC do SW

**v48 — Dois bugs críticos corrigidos (fluxo operador → admin)**

*Bug 1 — admin.html:*
- Supabase era atribuído a `window._supabase` mas todas as funções de relatório verificavam `window._sb`
- Resultado: `loadAtendRel()` retornava sem query; admin via "Carregando..." para sempre
- Fix: adicionado `window._sb = sb` ao lado de `window._supabase = sb`

*Bug 2 — atendimento-tablet.html / `upsertSessao`:*
- `const existing = ld(key)` retorna `{}` (padrão da função) quando chave não existe
- `concluido_at: existing || null` = `{} || null` = `{}` (objeto truthy)
- Supabase rejeitava `{}` em coluna `timestamptz` → erro silencioso no catch
- Resultado: ZERO linhas eram criadas pelo upsert progressivo (só `concluirTurno` gravava)
- Fix: `concluido_at: (existing && existing[tab]) || null`
- Após a fix: cada check do operador cria/atualiza uma linha com progresso real

**v49 — Fotos admin: signed URLs + lightbox popup**

*Problema:*
- Bucket `atendimento` é privado (`"public": false`)
- URLs armazenadas usavam `/object/public/atendimento/...` (funciona só para buckets públicos)
- Clicar na foto retornava 404 "Bucket not found"
- Thumbnails no admin também estavam quebradas pelo mesmo motivo

*Solução:*
- `_storagePath(url)`: extrai o path relativo da URL armazenada (strip `public/<bucket>/`)
- `window._sb.storage.from('atendimento').createSignedUrls(paths, 3600)`: gera tokens temporários (1h)
- `urlMap[path] = signedUrl` para lookup rápido por path
- Thumbnails renderizadas com signed URLs
- Clique abre lightbox popup: backdrop blur, fecha com `✕`, click-outside ou `Escape`
- `img.src = ''` ao fechar (evita flash da imagem anterior ao reabrir)
