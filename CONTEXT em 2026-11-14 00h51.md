### v48 — Correção fluxo admin → checklist (2 bugs críticos)
**Bug 1 — admin.html:** `window._supabase = sb` mas funções de relatório usavam `window._sb` → retornavam silenciosamente sem fazer query. Fix: `window._sb = sb` adicionado.

**Bug 2 — atendimento-tablet.html:** `upsertSessao` passava `concluido_at: existing || null` onde `existing = ld(key) = {}` (truthy). `{} || null = {}` → Supabase rejeitava `{}` em coluna `timestamptz` → erro silencioso, nenhuma linha era criada pelo upsert progressivo. Fix: `concluido_at: (existing && existing[tab]) || null`.

### v49 — Fotos admin: signed URLs + lightbox popup
**Problema:** bucket `atendimento` é privado. URLs salvas usavam `/object/public/...` → 404 "Bucket not found".
**Fix:**
- `_storagePath(url)` extrai o path relativo da URL armazenada
- `createSignedUrls(paths, 3600)` gera URLs temporárias autenticadas (1h)
- Thumbnails renderizam com signed URLs (também estavam quebradas)
- Clique abre lightbox popup com backdrop blur, fecha com `✕`, clique fora ou `Escape`

### Fluxo de dados operador → admin
1. Operador seleciona responsável → `setResp(tab, nome)` → localStorage + `upsertSessao`
2. Operador marca item → `toggleItem(id, tab)` → localStorage + `upsertSessao` (debounce 800ms)
3. Operador tira foto → `saveFoto` → base64 local → `uploadFoto` → Storage + `atendimento_fotos` + `upsertSessao`
4. Operador conclui turno → `concluirTurno` → upsert final com `concluido_at = now()`
5. Admin abre Relatórios → `loadAtendRel()` via `window._sb` → query `atendimento_sessoes`
6. Admin clica card → `showAtendDet(date)` → sessoes + fotos + signed URLs → lightbox

### localStorage
| Chave | Conteúdo |
|-------|----------|
